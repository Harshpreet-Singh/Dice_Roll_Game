# Dice Roll Game

This project is a simple dice roll game that simulates rolling dice using random number generation. The program is menu-driven and uses functions to handle game logic.

## Features
- Menu-based gameplay
- Random dice roll using built-in modules
- Modular code using functions
- Displays winner or result after each round

## How to Run
1. Clone the repository
2. Navigate to the project folder
3. Run the main file using your programming language

## Purpose
This project is designed to practice functions, random number generation, and basic program structure.
